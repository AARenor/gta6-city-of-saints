City of Saints: an original top-down open-world crime game for the browser. A city of 144 blocks with traffic, pedestrians, car theft, a five-star wanted level with police pursuit, four story missions, combat, a HUD with a minimap, a start screen and a save, all drawn with canvas paths, no network and no engine.

## Run it

```sh
python3 -m http.server 8891 --directory game
# then open http://127.0.0.1:8891/index.html
```
